## Once Upon A Katamari Xbox Game Pass Status: The Short Answer

Once Upon A Katamari Xbox Game Pass speculation has been running since the game was first announced, and the answer is simpler than most players expect. The game is a standalone purchase, and there is no indication that it is part of the Game Pass catalog. You do not need any subscription to play the story mode.

Where a subscription does matter is online play. The official Xbox Store listing for Once Upon A Katamari states that online multiplayer on console requires Xbox Game Pass Essential, Premium, or Ultimate — with those subscriptions sold separately. So the Once Upon A Katamari Xbox Game Pass connection is about online access, not about claiming the game for free.

That distinction matters before you spend money on the wrong thing. If you only care about the story, buy the game and skip the subscription entirely. If you want to roll with friends online on console, plan for a Game Pass tier on top of the purchase.
